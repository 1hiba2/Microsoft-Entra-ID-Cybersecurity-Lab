# Official Microsoft Technical References

## About This Project

This document contains Microsoft Learn references supporting the Microsoft Entra ID cybersecurity lab.

The project used Microsoft Entra ID Free, Azure Cloud Shell, Microsoft Graph PowerShell, and Windows 10.

- [Microsoft Entra ID documentation](https://learn.microsoft.com/en-us/entra/identity/)
- [Manage users in Microsoft Entra ID](https://learn.microsoft.com/en-us/entra/fundamentals/how-to-manage-users)
- [Administrative units in Microsoft Entra ID](https://learn.microsoft.com/en-us/entra/identity/role-based-access-control/administrative-units)
- [Microsoft Entra role-based access control](https://learn.microsoft.com/en-us/entra/identity/role-based-access-control/custom-overview)

**Related lab:** User management, security groups, administrative units, and least-privilege validation.

## Project Scope

This lab implemented free-tier features only.

Microsoft Entra ID Premium Conditional Access policies, privileged identity management, and paid hybrid infrastructure were not deployed.

These references are provided for technical learning and traceability. Linking a feature does not imply that every capability described in its documentation was implemented.

## Privacy

This document contains only public Microsoft documentation links and general project descriptions. It includes no tenant identifiers, real user principal names, credentials, or private security exports.
