# Lab 03 — Security Monitoring and Audit Logs

## 1. Objective

Investigate identity-related security events using Microsoft Entra ID audit logs and sign-in logs.

This lab demonstrates how an administrator can verify changes to directory objects, identify the actor responsible for an action, and investigate authentication results.
